# NBA 토토 도우미

선수별 통계 표(엑셀식), 팀 통계, 그리고 **부상자를 지정했을 때의 예상 스코어·총점·승리 확률**을 보여주는 프로그램입니다.
추가 설치 없이 macOS 기본 Python과 웹 브라우저만 있으면 됩니다.

## 사용법
1. `시작하기.command`를 더블클릭 → 최신 데이터를 받고 화면이 열립니다.
   (터미널에서 `python3 update_data.py` 실행 후 `index.html`을 열어도 같음)
2. **경기 예측** 탭: 왼쪽에서 경기를 고르거나 팀을 직접 선택 → 아래 로스터에서 결장 선수 체크
3. **토토 배당 계산기**: 베트맨 배당을 넣으면 모델 확률 기준 기대값(+/-)을 보여줍니다.
4. **선수 통계 / 팀 통계** 탭: 열 제목 클릭으로 정렬, `엑셀(CSV) 저장` 버튼으로 내보내기.
   `data/선수통계_*.csv` 파일도 업데이트할 때마다 같이 만들어집니다.

## 파일
- `update_data.py` — Basketball-Reference(통계), ESPN(로스터·부상·일정·시장 라인)에서 데이터 수집
- `index.html`, `app.js`, `style.css` — 화면과 예측 모델
- `data/` — 받은 데이터 (`cache/`는 3시간 동안 재사용, `--force`로 강제 새로 받기)

예측은 통계 모델 참고용이며 결과를 보장하지 않습니다.

## 핸디캡·언더오버 시나리오 분석

1. 경기를 선택하고 **홈팀 기준 핸디캡**과 **총점 기준점**을 입력합니다. 홈 -3.5는 홈팀이 4점 이상 이겨야 적중하는 방향입니다.
2. 로스터에서 결장을 체크하거나 예상 출전시간을 입력합니다. 입력한 시간은 고정하고, 나머지 선수에게 자동 배분합니다. 빈칸으로 지우면 자동으로 돌아갑니다.
3. 양 팀 합계가 각각 240분이어야 예측합니다. 선수별 최대 시간은 40분이며, 기록 없는 선수도 직접 시간을 지정할 수 있습니다. 이 경우 선수 평가는 모델 사전값을 사용합니다.
4. ‘정상 출전’, ‘20분 제한’, ‘결장’ 등의 이름으로 최대 3개 시나리오를 저장합니다. 표에서 예상 점수차·총점과 기준점 대비 차이를 비교합니다. 저장한 시나리오의 출전·보정 설정은 보존하며 현재 기준점과 모델 설정으로 다시 계산합니다.
5. 정수 기준점은 동점 확률을 별도 표시합니다. 실제 상품의 동점 처리가 원금 환급인지 미적중인지 확인하고 선택하세요. 미확인 상태에서는 기대값을 보류합니다. 정산 선택은 핸디캡·언더오버에 공통 적용됩니다.

시나리오는 브라우저에 경기·데이터 갱신 시점별로 보관합니다. 다른 경기나 새 데이터에는 이전 경기의 결장 설정을 자동 적용하지 않습니다. 초기화는 현재 경기의 결장·출전시간을 되돌리며 저장한 비교 시나리오는 삭제 버튼으로 지웁니다.

데이터 상태 패널은 누락 통계, 중복 ID, 자료 시각을 표시합니다. 기존 첨부 데이터에는 시간대가 없으므로 최신 여부를 확정하지 않습니다. 이후 업데이트는 UTC 시간대를 기록합니다. Dillon Mitchell에게 잘못 연결됐던 Davion Mitchell의 통계는 제거했으며, 불확실한 이름 연결은 추측하지 않습니다.

모델 확률과 기대값은 과거 성능으로 보정하지 않은 추정값입니다. 정수 점수의 동점 확률은 정규분포의 연속성 보정으로 근사합니다. 정규시간 240분 모델로 연장을 따로 예측하지 않으며, 포지션별 대체·라인업 효과·팀 통계에 이미 반영된 결장의 중복 보정 문제는 후속 검증 대상입니다. 최신 데이터 재수집과 과거 경기 백테스트는 이번 변경 범위에 포함하지 않았습니다.

## 개발 및 검증

추가 앱 의존성 없이 `python3 -m http.server 8000 --bind 127.0.0.1`로 실행합니다.

- `python3 tests/test_data.py`: 선수 연결과 첨부 데이터 회귀 검사
- `node tests/test_model.js`: 30팀 출전시간 합계·고정 시간·결장 우선 처리·확률 합계·핸디 부호 검사
- `python3 tests/test_browser.py`: Playwright 및 `/usr/bin/chromium`이 설치된 환경에서 입력·저장·새로고침·경기 분리·정산·잘못된 로테이션 UI 검사
